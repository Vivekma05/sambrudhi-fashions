Connect this phone

The admin page saves your products into your GitHub repository, which is where the website lives. It needs a key from GitHub once on each phone or computer.

  1. Open GitHub → New access token (sign in as ).
  2. Token name: Shop admin. Expiration: choose the longest option.
  3. Repository access: Only select repositories → .
  4. Permissions: Repository permissions → Contents → Read and write.
  5. Tap Generate token, copy it, and paste it below.
  6. Choose a PIN. You'll type it each time you open this page.

The key is saved only on this device, locked with your PIN. Anyone who has the key can change your shop, so don't share it.
